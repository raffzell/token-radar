A token launch radar: it ranks DefiLlama protocols that record no token by an implied value computed from the sealed snapshot alone — TVL, seven-day growth, age with no token recorded, and chain breadth — and gives each protocol a concrete farm plan with costs and times, in a sortable, filterable dashboard with a detail view per protocol.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input <snapshot.json>
```
